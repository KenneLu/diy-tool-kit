## 1. 五个工具（四个既有 + render CLI 参照）

本文件用于新工具“逐项对照”，不是要求所有工具立刻改成相同形态。

| 工具 | 主类型 | 当前文档状态 | release exe 位置 |
|---|---|---|---|
| `dsh-helper` | 托盘 | 根目录无 `docs/`；仅 README/CHANGELOG | 版本目录内 |
| `local-speak2text` | 托盘 | 根目录无 `docs/`；仅 README/CHANGELOG | 版本目录内 |
| `opencodex-helper` | 托盘 | 根目录无 `docs/`；仅 README/CHANGELOG | 版本目录内 |
| `reme-helper` | 托盘 | 已从 `doc/` 迁到 `docs/`；`docs/capture*.mjs` 为历史例外 | 版本目录内 |
| `render-before-code` | 命令行 | 已从 `doc/` 迁到 `docs/`，`skills/` 在根目录 | 版本目录根 |

说明：

- 前三个工具没有独立文档目录，README/CHANGELOG 已满足用户文档要求；不强制创建 docs/；
- 四个既有工具（dsh-helper、local-speak2text、opencodex-helper、reme-helper）都是托盘类型，不能直接套用 `工具类型/命令行工具.md`；
- `render-before-code` 是 CLI 类型参照实现；
- legacy 例外只适用于既有工具，新工具不得引用为例外；
- 工具版本、路径和发布布局以各工具仓当前实际为准，不在本表冻结。
