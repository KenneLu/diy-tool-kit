## §4 本轮裁定与发现

### 4.1 【判据假绿】C-40 用 `APP_ID` 查 Run 键，而契约是 `APP_NAME`

**事实链（全部可复跑）**：

```bash
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Run"
```
实测存在：`LocalSpeak2Text  REG_SZ  "...\local-speak2text\release\local-speak2text-1.4.0\local-speak2text.exe"`

而 `conformance_check.py` 的 C-40 输出 `Run[local-speak2text]=（无）`。

**根因不是"判据用错了一个常量"，而是"家族里 Run 键名没有单一契约"**：

| 工具 | autostart 形态 | 键名取自 | 实测 Run 键名 | C-40（用 `APP_ID`）结果 |
|---|---|---|---|---|
| l-s2t | **模板** `autostart` | `APP_NAME` | `LocalSpeak2Text` | **漏（假绿）** |
| dsh | — | — | `dsh-helper` | ✓（`APP_ID == APP_NAME`，无法区分） |
| ocx | — | — | `opencodex-helper` | ✓（同上） |
| reme | **内联** | **`APP_ID`** | `reme-helper` | ✓ |

依据（全部读源码）：
- 模板契约用 `APP_NAME`：`modules/autostart/autostart.py:44`（读）/`:53`（写）/`:113`（自愈）。
- reme 内联用 **`APP_ID`**：`reme-helper/src/main.py:3577`（读）/`:3589`（写）/`:3592`（删）。
- l-s2t 的 `appconfig.py:13` 注释：`APP_NAME = "LocalSpeak2Text"  # 历史注册表自启键名，改名 = 断链（NAME-05），不得擅动`。

⇒ C-40 任选其一都会漏掉另一半。**正确修法是"不依赖键名"**：枚举 Run 表全部值，
按目标路径是否落在该工具 `release/**`（或稳定安装位）之下来认领。
⇒ **C-40 对 l-s2t 的强断言（自启目标必须指向 `release/<VERSION>/`）从未执行**。
⛔ **不要**为了修判据去改任何一方的键名常量 —— l-s2t 那条是**历史注册表键名，改名 = 断链**（NAME-05），属**允许的差异**。

**为什么这比"少一条检查"更贵**：它让 `CONFORMANCE.md §4.1.42` 的结论
「l-s2t 无 Run 项（未设自启）⇒ 强断言不适用」**一起错了** —— 判据与文档互相佐证一个假结论
（与 §4.1.10b / §4.1.24 同族）。
