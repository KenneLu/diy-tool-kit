
## 取证与汇报纪律（`STANDARDS.md §D8` 的核心）

- **锚 = `(commit, path, blob)`，从不取工作树哈希**（寿命 < 5 分钟，实测）。
- **每条判据输出必须带判据自身的身份**（版本 + 归一哈希）。"C-44 ok"没有价值。
- **身份横幅 = 哈希 + `git status` 为空**，两件同时成立才有效。
- **"冻"的唯一判据是 `git status --porcelain` 为空**，不是任何一方的描述。
- **扫描面必须声明**；且**必须排除"引用被禁形态的说明文字"**。
- **时间戳带日期、行号带 commit、计数带时点** —— 证据的每个维度都不能丢。
- **"只发生一次"的动作（构建 / 改名保留 / 删除），第一次就要全量落盘**；
  `tail` 只能用于看结果，不能用于留证据。
- **手工抄写的表格必然滞后** ⇒ 让判据去读产物，不要抄。
- **可以不等而先做，必须同时满足三条**：① 危害即时且具体；② 修法可逆、**且不碰任何正在被拷贝的东西**；
  ③ 把推翻的开关交给别人。**缺一条就必须先等。**
